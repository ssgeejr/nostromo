# NOSTROMO

NOSTROMO is a standalone Debian Linux server used as an experimental environment for:

- System administration and software testing
- Local AI models, agents, and automation
- Codex and Grok experimentation
- Development, infrastructure, and integration testing

This repository contains the documentation, configuration, and automation used to manage and test the server. Working configurations and data should be preserved unless a task explicitly requires otherwise.

Deployment documentation:

- [`SYSTEM.md`](SYSTEM.md) — authoritative system and software inventory
- [`CODEX_LLAMA_CPP.md`](CODEX_LLAMA_CPP.md) — Qwen-backed Codex deployment
- [`HERMES.md`](HERMES.md) — Hermes Desktop, Computer Use, and GRAVITYDRIVE deployment
